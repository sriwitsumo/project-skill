# การค้นและตรวจสอบแหล่งอ้างอิง

## ลำดับค้น

1. แตกหัวข้อเป็น 3–6 แนวคิด/ตัวแปรหลัก และสร้างคำค้นไทย–อังกฤษพร้อมคำพ้อง
2. ค้นแนวคิด/ทฤษฎีจากตำรา คู่มือมาตรฐาน หน่วยงานเจ้าของเรื่อง หรือบทความทบทวนที่น่าเชื่อถือ
3. ค้นงานวิจัยไทยจากคลังมหาวิทยาลัย ThaiJO/TCI หรือวารสารต้นฉบับ และค้นงานต่างประเทศจากวารสาร ฐานข้อมูล
   วิชาการ หรือเว็บไซต์ผู้จัดพิมพ์
4. เปิดหน้าต้นฉบับหรือ PDF ตรวจชื่อผู้แต่ง ปี ชื่อเรื่อง วิธีศึกษา กลุ่มตัวอย่าง และข้อค้นพบก่อนจดบันทึก
5. ค้นย้อนหลังจากรายการอ้างอิงได้ แต่ต้องเปิดและตรวจต้นฉบับที่นำมาใช้ ไม่อ้างต่อจากแหล่งรองโดยไม่ระบุ

ไม่กำหนดจำนวนงานแบบตายตัว ให้ครอบคลุมทุกประเด็นสำคัญและทำตามเกณฑ์สถาบัน หากหลักฐานด้านใดบาง ให้รายงาน
ว่าบางแทนการเติมรายการให้ครบจำนวน

## บันทึกหลักฐานขั้นต่ำต่อแหล่ง

| ช่อง | สิ่งที่ต้องตรวจ |
|---|---|
| ผู้แต่ง/องค์กร | สะกดตามต้นฉบับและรู้ว่าเป็นบุคคลหรือหน่วยงาน |
| ปี | ปีเผยแพร่จริงและระบบปีที่ใช้ |
| ชื่อเรื่อง/แหล่งตีพิมพ์ | ตรงกับหน้าต้นฉบับ |
| URL/DOI | เปิดได้และชี้ไปยังต้นฉบับหรือระเบียนทางการ |
| วัตถุประสงค์/วิธี/กลุ่ม | สรุปจากเนื้อหาจริง ไม่เดาจากชื่อเรื่อง |
| ผลสำคัญ | ใช้เฉพาะผลที่ต้นฉบับรายงาน |
| ความเกี่ยวข้อง | ระบุว่าจะรองรับแนวคิด ตัวแปร วิธี หรือช่องว่างใด |

## ด่านห้ามเออเอง

- ถ้าเปิดต้นฉบับไม่ได้ อย่ายืนยันวิธีหรือผลการศึกษา
- ถ้าชื่อ/ปีขัดกัน ให้ตรวจหน้าวารสาร PDF และ DOI; หากยังไม่ยุติให้ติดป้าย `[ตรวจสอบปีพิมพ์จากต้นฉบับ]`
- ถ้ามีไฟล์ผู้ใช้ ให้ดึงตัวเลขจากไฟล์จริงและแจ้งเมื่อไม่ตรงกับข้อความที่ผู้ใช้จำมา
- เก็บ URL ของทุกแหล่งที่ใช้เพื่อส่งให้ผู้ใช้ตรวจย้อนหลังได้
