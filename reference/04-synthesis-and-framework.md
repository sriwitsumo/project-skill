# การสังเคราะห์งานวิจัยและสร้างกรอบแนวคิด

## สรุปงานหนึ่งชิ้นอย่างมีหน้าที่

ในแต่ละงานให้ตอบเท่าที่เกี่ยวข้อง: ใคร/ปี ศึกษาอะไร บริบทหรือกลุ่มใด ใช้วิธีใด พบอะไร และข้อค้นพบนั้นรองรับ
หรือแตกต่างจากโครงงานนี้อย่างไร อย่าคัดลอกบทคัดย่อทั้งย่อหน้า และอย่ากล่าวเพียงว่า “สอดคล้องกับงานนี้”
โดยไม่บอกมิติที่สอดคล้อง

## สังเคราะห์ข้ามงาน

หลังงาน 2–4 ชิ้นในหมวดเดียวกัน ให้เขียนย่อหน้าสังเคราะห์ที่:

1. ระบุข้อค้นพบร่วม
2. ชี้ความแตกต่างด้านบริบท วิธี ตัวแปร หรือผล
3. บอกข้อจำกัด/ช่องว่างโดยไม่กล่าวเกินหลักฐาน
4. ระบุสิ่งที่นำมาใช้กำหนดแนวทางของโครงงานนี้

จัดหมวดตามสาระก่อนภูมิศาสตร์เมื่อช่วยให้เห็นภาพชัด เช่น “การตรวจวัด”, “การควบคุม”, “การประเมินผู้ใช้”
แล้วแบ่งงานในประเทศ/ต่างประเทศภายในแต่ละหมวด หากแบบสถาบันบังคับแยกประเทศ ให้ทำตามแบบนั้นแต่ยังสร้าง
หัวข้อย่อยตามประเด็นภายในแต่ละส่วน

## กรอบแนวคิด

สร้างกรอบจากแหล่งที่ทบทวนจริง ไม่ใส่ลูกศรเพียงเพราะดูเป็นงานวิจัย:

- งานตัวแปร: ตัวแปรต้น/ปัจจัย → กลไกตามทฤษฎี → ตัวแปรตาม โดยระบุตัวแปรควบคุมเมื่อมีเหตุผล
- สิ่งประดิษฐ์: หลักการ/ข้อกำหนด → องค์ประกอบออกแบบ → การทำงาน → เกณฑ์ประเมิน
- โปรแกรม: ความต้องการ/ข้อมูลนำเข้า → กระบวนการ/ฟังก์ชัน → ผลลัพธ์ → คุณภาพการใช้งาน
- วิจัยในชั้นเรียน: ทฤษฎีการเรียนรู้ → นวัตกรรม/กิจกรรม → พฤติกรรมการเรียนรู้ → ผลลัพธ์การเรียน

อธิบายผังเป็นร้อยแก้วสั้น ๆ และตรวจว่าทุกกล่องมีแหล่งรองรับหรือมาจากขอบเขตที่ผู้ใช้ให้จริง

## ย่อหน้าปิดบท

สรุปเฉพาะองค์ความรู้ที่นำไปใช้ เช่น หลักการที่เลือก องค์ประกอบที่จะพัฒนา ตัวแปรหรือเกณฑ์ประเมิน และช่องว่างที่
โครงงานจะศึกษา ห้ามย้อนเล่าปัญหา/ความสำคัญจากบทที่ 1 และห้ามบรรยายขั้นตอนปฏิบัติจากบทที่ 3
