# นิยามศัพท์เฉพาะ — คู่มือเจาะลึก

## หน้าที่ของหัวข้อนี้

ตอบคำถาม: **"คำเฉพาะที่ใช้ซ้ำ ๆ ในเล่มนี้ เมื่อคณะผู้จัดทำใช้คำนี้ หมายถึงอะไรกันแน่"** เป็นการนิยามแบบ
**เชิงปฏิบัติการ (operational definition)** คือนิยามตามที่ใช้จริงในโครงงานนี้เท่านั้น ไม่ใช่นิยามตามพจนานุกรม
หรือนิยามทางวิชาการทั่วไป

## เกณฑ์เลือกคำที่ต้องนิยาม (ไม่ใช่ทุกคำต้องนิยาม)

นิยามเฉพาะคำที่เข้าเงื่อนไขข้อใดข้อหนึ่งต่อไปนี้เท่านั้น:

1. **คำที่มีความหมายกำกวมได้หลายแบบ** ถ้าไม่กำหนดให้ชัด ผู้อ่านอาจเข้าใจต่างจากที่คณะผู้จัดทำตั้งใจ เช่น
   คำว่า "ประสิทธิภาพ" ในโครงงานหนึ่งอาจหมายถึง "ความแม่นยำ" แต่อีกโครงงานหนึ่งอาจหมายถึง "ความเร็ว"
   — ต้องระบุให้ชัดว่าในเล่มนี้วัดจากอะไร
2. **คำที่เป็นตัวแปรหลักของโครงงาน** และจะถูกใช้ซ้ำตลอดทั้งเล่ม (โดยเฉพาะในบทที่ 3 และบทที่ 4) ต้องนิยาม
   ให้ผู้อ่านเข้าใจตรงกันตั้งแต่ต้น
3. **คำศัพท์เทคนิคเฉพาะทาง** ที่ผู้อ่านทั่วไป (ไม่ใช่ผู้เชี่ยวชาญ) อาจไม่คุ้นเคย
4. **คำที่คณะผู้จัดทำ "บัญญัติ" ขึ้นใช้เอง** สำหรับโครงงานนี้โดยเฉพาะ (เช่น ตั้งชื่อเรียกสั้น ๆ แทนชื่อเต็มของ
   สิ่งประดิษฐ์)

**ห้ามนิยามคำทั่วไปที่ไม่กำกวมอยู่แล้ว** เช่น นิยามคำว่า "นักเรียน" "โรงเรียน" "น้ำ" — สิ่งเหล่านี้ทำให้หัวข้อดู
ยืดเยื้อและไม่จำเป็น (เว้นแต่คำนั้นถูกใช้ในความหมายเฉพาะทางที่ต่างจากความหมายทั่วไปจริง ๆ)

## รูปแบบการเขียนนิยาม

```
[คำศัพท์] หมายถึง [คำอธิบายความหมายตามที่ใช้ในโครงงานนี้] [ถ้าเป็นตัวแปรที่วัดผลได้ ให้ระบุวิธีวัด/เกณฑ์ด้วย]
```

**ตัวอย่างที่ดี** (นิยามเชิงปฏิบัติการ ระบุวิธีวัดชัดเจน):

> **ประสิทธิภาพของเครื่องรดน้ำต้นไม้อัตโนมัติ** หมายถึง ความสามารถของเครื่องในการรักษาระดับความชื้นใน
> ดินให้อยู่ในช่วงร้อยละ 60-70 ได้อย่างต่อเนื่องเป็นระยะเวลา 7 วัน โดยไม่ต้องมีการรดน้ำเสริมด้วยมือ
>
> **เซนเซอร์วัดความชื้นในดิน** หมายถึง อุปกรณ์อิเล็กทรอนิกส์ที่ใช้วัดปริมาณความชื้นในดินแล้วแปลงเป็นค่า
> สัญญาณไฟฟ้าเพื่อส่งต่อให้ชุดควบคุมประมวลผลในการสั่งเปิด-ปิดปั๊มน้ำ

**ตัวอย่างที่แย่** (นิยามกว้าง วัดผลไม่ได้ เหมือนคัดลอกมาจากพจนานุกรม):

> **ประสิทธิภาพ** หมายถึง ความสามารถในการทำงานได้ดี

ทำไมถึงแย่: "ทำงานได้ดี" ไม่ได้บอกเกณฑ์ที่วัดผลได้จริง ผู้อ่านไม่รู้ว่าต้องดูอะไรถึงจะเรียกว่า "ดี" และเมื่อไป
ถึงบทที่ 4 ผลการทดลอง จะไม่มีเกณฑ์อ้างอิงกลับมาที่นิยามนี้ได้เลย

## จุดเชื่อมกับหัวข้ออื่น (ป้องกันการวกวน)

นิยามศัพท์เฉพาะมักซ้ำกับหัวข้อขอบเขตเพราะทั้งคู่พูดถึง "ตัวแปร" เหมือนกัน วิธีแยกหน้าที่ให้ชัดคือ:

- **ขอบเขต** บอกว่า "ตัวแปรอะไรบ้างที่เกี่ยวข้องกับการศึกษานี้" (รายการ)
- **นิยามศัพท์เฉพาะ** บอกว่า "ตัวแปรแต่ละตัวนั้น เมื่อพูดถึงในเล่มนี้ วัดผล/นับอย่างไร" (คำอธิบายเชิงลึกของ
  แต่ละตัวแปร)

ดังนั้นให้เขียนขอบเขตให้เป็นรายการสั้น ๆ ก่อน แล้วค่อยขยายความรายละเอียดของคำที่กำกวมในหัวข้อนิยามศัพท์
อย่าอธิบายรายละเอียดเดียวกันซ้ำสองที่

## เรียงลำดับคำอย่างไร

เรียงตามลำดับที่คำนั้นถูกกล่าวถึงครั้งแรกในเล่ม (มักจะเรียงจากคำที่เกี่ยวกับแก่นของโครงงานไปหาคำย่อย) ไม่ใช่
เรียงตามตัวอักษร ก-ฮ (ยกเว้นสถาบันกำหนดให้เรียงตามตัวอักษร ให้ทำตามข้อกำหนดของสถาบันนั้น)

## Checklist ก่อนถือว่าหัวข้อนี้เสร็จ

- [ ] มีเฉพาะคำที่กำกวม/เป็นตัวแปรหลัก/เทคนิคเฉพาะ/บัญญัติขึ้นเอง ไม่ใส่คำทั่วไปที่ไม่จำเป็น
- [ ] ทุกนิยามระบุวิธีวัด/เกณฑ์ที่จับต้องได้ (ถ้าเป็นตัวแปรที่วัดผล) ไม่ใช้คำกว้างอย่าง "ดี" "มีประสิทธิภาพ" ลอย ๆ
- [ ] ไม่ซ้ำเนื้อหากับรายการตัวแปรในหัวข้อขอบเขต
- [ ] ภาษาเป็นทางการ กระชับ ไม่ใช่การคัดลอกจากพจนานุกรม
