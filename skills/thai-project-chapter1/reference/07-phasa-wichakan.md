# ภาษาไทยเชิงวิชาการ — คลังคำ ไวยากรณ์ และกฎที่ต้องยึดตลอดทั้งเล่ม

เนื้อหาในไฟล์นี้อ้างอิงหลักการเขียนงานวิชาการภาษาไทยจากบทความ "ปัญหาในงานเขียนของนักศึกษา" โดย
ยุกติ มุกดาวิจิตร (นักวิชาการด้านมานุษยวิทยา) ผสมกับธรรมเนียมการเขียนรายงานโครงงาน/งานวิจัยไทยที่ใช้
กันทั่วไปในสถานศึกษา ใช้ไฟล์นี้ตรวจสอบภาษาทุกครั้งหลังเขียนแต่ละหัวข้อเสร็จ ไม่ใช่แค่ตอนจบทั้งเล่ม

## 1. ประโยคต้องสมบูรณ์เสมอ: ประธาน + กริยา (+ กรรม)

ปัญหาที่พบบ่อยที่สุดในงานเขียนวิชาการไทยคือการเขียนประโยคที่ไม่จบ หรือใช้คำเชื่อมร้อยประโยคหลาย ๆ
ประโยคเข้าด้วยกันจนไม่รู้ว่าประธานคือใคร ก่อนปล่อยประโยคไหนผ่าน ให้ถามตัวเองว่า "ประโยคนี้มีประธานที่
ชัดเจนไหม" และ "อ่านจบแล้วได้ใจความสมบูรณ์ในตัวเองไหม โดยไม่ต้องพึ่งประโยคก่อนหน้า"

**ตัวอย่างประโยคที่ขาด (ผิด)**:
> "ซึ่งทำให้นักเรียนไม่สามารถจัดการเวลาได้อย่างเหมาะสม และส่งผลกระทบต่อผลการเรียน"

ปัญหา: เริ่มประโยคด้วย "ซึ่ง" โดยไม่มีประธาน ทำให้ประโยคนี้ไม่สามารถยืนได้ด้วยตัวเอง (ต้องพ่วงกับประโยค
ก่อนหน้าเสมอ ซึ่งถ้าเผลอแยกย่อหน้าไปจะกลายเป็นประโยคขาด)

**แก้เป็น**:
> "ปัญหาดังกล่าวทำให้นักเรียนไม่สามารถจัดการเวลาได้อย่างเหมาะสม และส่งผลกระทบต่อผลการเรียนโดยตรง"

### ประโยคเงื่อนไข/เหตุผล ต้องมีครบสองท่อน

ประโยคภาษาไทยที่เป็นเงื่อนไขหรือแสดงเหตุผล (ซึ่งงานวิชาการใช้บ่อยมาก) ต้องมีคำคู่ครบทั้งสองฝั่ง ห้ามขึ้นต้น
ท่อนแรกแล้วลืมท่อนหลัง:

| คู่คำที่ต้องมีครบ | ตัวอย่างประโยคที่ถูก |
|---|---|
| หาก... (แล้ว)... | หากไม่มีการควบคุมความชื้นในดินอย่างสม่ำเสมอ ผักสวนครัวก็มีแนวโน้มเหี่ยวเฉาได้ง่าย |
| เนื่องจาก...จึง... | เนื่องจากนักเรียนต้องผลัดเวรกันดูแลแปลงผัก การรดน้ำจึงขาดความสม่ำเสมอ |
| แม้...แต่/หากแต่ว่า... | แม้จะมีตารางเวรรดน้ำอยู่แล้ว แต่ก็ยังไม่สามารถแก้ปัญหาผักเหี่ยวเฉาได้อย่างสมบูรณ์ |
| ถึงแม้...ก็ตาม | ถึงแม้จะมีการปรับตารางเวรใหม่แล้วก็ตาม ปัญหาการขาดน้ำในวันหยุดก็ยังคงเกิดขึ้น |

## 2. คำที่ใช้ผิดบ่อยที่สุด: "ซึ่ง" และ "โดย"

**"ซึ่ง"** ใช้ขึ้นต้น "ส่วนขยาย" ของประโยคเดิมเท่านั้น (ต้องมีประโยคหลักอยู่ก่อนแล้วในประโยคเดียวกัน) **ห้ามใช้
ขึ้นต้นประโยคใหม่หรือขึ้นต้นย่อหน้าใหม่เด็ดขาด** เพราะจะทำให้ประโยคนั้นไม่มีประธานเป็นของตัวเอง

- ✅ ถูก: "โรงเรียนมีแปลงผักสวนครัวจำนวน 20 แปลง ซึ่งนักเรียนทุกระดับชั้นผลัดเปลี่ยนกันดูแล" (ซึ่ง ขยาย
  "แปลงผักสวนครัว" ในประโยคเดียวกัน)
- ❌ ผิด: "โรงเรียนมีแปลงผักสวนครัวจำนวน 20 แปลง ซึ่งทำให้การดูแลเป็นเรื่องยาก" (ถ้าตั้งใจให้เป็นประโยค
  แยก ต้องเปลี่ยนเป็น "การมีแปลงผักจำนวนมากทำให้การดูแลเป็นเรื่องยาก" แทน)

**"โดย"** ใช้เชื่อมส่วนขยายที่บอกวิธีการ/ผู้กระทำ ไม่ใช่ตัวเชื่อมประโยคเต็ม ๆ ต่อกันเรื่อย ๆ ถ้าพบว่าในย่อหน้า
เดียวใช้ "โดย" เกิน 2 ครั้ง มักเป็นสัญญาณว่ากำลังร้อยประโยคยาวเกินไป ให้ลองตัดเป็นประโยคสั้นลง

## 3. ห้ามขึ้นต้นประโยคหรือย่อหน้าด้วย "และ" หรือ "แต่"

ทั้งสองคำมีทางเลือกที่ให้น้ำหนักความเป็นทางการมากกว่าเมื่อต้องขึ้นต้น:

| แทน "และ" (เมื่อขึ้นต้นประโยค/ย่อหน้า) | แทน "แต่" (เมื่อขึ้นต้นประโยค/ย่อหน้า) |
|---|---|
| นอกจากนี้ | อย่างไรก็ตาม |
| นอกจากนั้น | อย่างไรก็ดี |
| ยิ่งกว่านั้น | แม้กระนั้น |
| พร้อมกันนั้น / พร้อม ๆ กันนั้น | แต่ทว่า |
| ในขณะเดียวกัน | หากแต่ว่า |

## 4. คลังคำเชื่อมความคิดเป็นทางการ (แยกตามหน้าที่)

ใช้สลับกันไปในแต่ละย่อหน้า อย่าใช้คำเดียวซ้ำทุกครั้งจนดูจำเจ:

- **เพิ่มเติม/ขยายความ**: นอกจากนี้ / ยิ่งไปกว่านั้น / อีกทั้ง / ควบคู่ไปกับ...
- **แสดงเหตุผล/ที่มา**: เนื่องจาก / ด้วยเหตุนี้ / ดังนั้น / จึงเป็นที่มาของ...
- **แสดงความขัดแย้ง/ข้อจำกัด**: อย่างไรก็ตาม / แม้ว่า...ก็ตาม / ในทางกลับกัน / ทว่า
- **สรุป/ปิดประเด็น**: กล่าวโดยสรุป / จากที่กล่าวมาข้างต้น / ด้วยเหตุผลดังกล่าว
- **เปรียบเทียบ**: เมื่อเทียบกับ / ในทำนองเดียวกัน / แตกต่างจาก...ตรงที่

## 5. คำที่ห้ามใช้ในงานวิชาการ (และคำแทนที่เป็นทางการ)

| ห้ามใช้ (ภาษาพูด) | ใช้แทน (ภาษาทางการ) |
|---|---|
| เยอะ / เยอะแยะ / แยะ | จำนวนมาก / เป็นจำนวนมาก |
| นิดหน่อย / นิดเดียว | เล็กน้อย |
| โอเค / ok | เหมาะสม / ยอมรับได้ / ใช้ได้ |
| ทำให้...ดีขึ้นเยอะ | ทำให้...ดีขึ้นอย่างมีนัยสำคัญ / เพิ่มขึ้นอย่างชัดเจน |
| เจ๋ง / เท่ห์ / สุดยอด | โดดเด่น / มีประสิทธิภาพสูง |
| เด็ก ๆ (หมายถึงนักเรียน) | นักเรียน |
| หนู/ผม/ดิฉัน (สรรพนามส่วนตัว) | คณะผู้จัดทำ / ผู้วิจัย / ผู้ศึกษา |
| เอาไปทำ / เอามาใช้ | นำไปใช้ / นำมาประยุกต์ใช้ |
| คำทับศัพท์อังกฤษพร่ำเพรื่อ (เช่น "ฟีเจอร์เจ๋ง ๆ") | ใช้คำไทยที่มีความหมายตรง หรือทับศัพท์เฉพาะเมื่อไม่มีคำไทยที่กระชับเท่า (เช่น เซนเซอร์ แอปพลิเคชัน ยังใช้ได้เพราะเป็นศัพท์เทคนิคที่ยอมรับทั่วไป) |
| คำเน้นย้ำซ้ำ ๆ เช่น "นั้น" พร่ำเพรื่อ | ตัดออกถ้าไม่จำเป็นต่อความหมาย |

## 6. การเว้นวรรค (กฎที่ใช้บ่อยที่สุด)

1. เว้นวรรค 1 เคาะเมื่อจบประโยค (ไม่มีจุดจบประโยคในภาษาไทยแบบภาษาอังกฤษ ต้องใช้การเว้นวรรคแทน)
2. เมื่อแสดงรายการของสิ่งที่กล่าวถึงต่อเนื่องกัน ให้เว้นวรรคคั่นแทนจุลภาค (,) เช่น "ได้แก่ ผักบุ้ง คะน้า และ
   กวางตุ้ง" ไม่ใช่ "ได้แก่ ผักบุ้ง, คะน้า, และกวางตุ้ง" (เครื่องหมาย , ไม่ใช่ธรรมเนียมมาตรฐานของภาษาไทย)
3. เว้นวรรคระหว่างตัวอักษรกับตัวเลข เช่น "จำนวน 30 คน" ไม่ใช่ "จำนวน30คน"
4. ไม้ยมก (ๆ) เว้นวรรคทั้งก่อนและหลังเสมอ เช่น "ต่าง ๆ นานา" ไม่ใช่ "ต่างๆนานา" หรือ "ต่างๆ นานา"
5. อย่าเว้นวรรคถี่เกินความจำเป็นเพื่อ "เน้นคำ" — ถ้าต้องการเน้น ให้ใช้เครื่องหมายอัญประกาศ "..." แทน
6. หลีกเลี่ยงเครื่องหมายวรรคตอนแบบภาษาอังกฤษที่ไม่มีธรรมเนียมในภาษาไทย เช่น เครื่องหมายขีด – หรือ —
   (dash) ใช้คำว่า "ที่" "ซึ่ง" "อัน" แทนการสร้างประโยคซ้อนแบบภาษาอังกฤษ

## 7. เขียนอย่างไรให้ "สวยแต่ยังเป็นทางการ" (ไม่ใช่ดอกไม้ดอกใบเวิ่นเว้อ)

ความสวยงามในงานวิชาการไม่ได้มาจากคำฟุ่มเฟือยหรือคำเชิงกวี แต่มาจาก 3 อย่างนี้:

1. **จังหวะประโยคที่มีความยาวสลับกัน** — อย่าเขียนประโยคยาวเท่ากันทุกประโยคจนอ่านแล้วรู้สึกซ้ำจังหวะ
   สลับประโยคสั้น-กระชับ กับประโยคยาว-ให้รายละเอียด เพื่อให้จังหวะการอ่านลื่นไหล
2. **คำกริยาที่เจาะจง แทนคำกริยากว้าง ๆ** — แทนที่จะใช้ "ทำ" "มี" "ได้" ซ้ำ ๆ ให้เลือกกริยาที่สื่อความหมาย
   เฉพาะเจาะจงกว่า เช่น แทน "ทำให้ผักโตดี" ด้วย "ส่งเสริมการเจริญเติบโตของผัก" แทน "มีปัญหา" ด้วย
   "ประสบปัญหา" หรือ "เผชิญกับปัญหา"
3. **ความสม่ำเสมอของคำศัพท์หลัก** — คำศัพท์ที่เป็นแก่นของโครงงาน (ชื่อสิ่งประดิษฐ์ ชื่อตัวแปรหลัก) ต้องใช้
   คำเดียวกันตลอดทั้งเล่ม ห้ามสลับใช้คำพ้องความหมายเพื่อความหลากหลาย (เช่น สลับเรียก "เครื่องรดน้ำ
   อัตโนมัติ" ว่า "อุปกรณ์รดน้ำอัจฉริยะ" บ้าง "ระบบให้น้ำอัตโนมัติ" บ้าง) เพราะจะทำให้ผู้อ่านสับสนว่าเป็นสิ่ง
   เดียวกันหรือไม่ ความสวยงามเชิงวิชาการมาจาก "ความชัดเจนที่สม่ำเสมอ" ไม่ใช่ "ความหลากหลายของคำ"

## 7.5 ระดับความเป็นทางการ: ต้องเทียบเท่าหนังสือราชการ ไม่ใช่แค่ภาษาวิชาการทั่วไปแบบผ่าน ๆ

**มาตรฐานขั้นต่ำของสกิลนี้คือระดับภาษาราชการ/ภาษาทางการขั้นสูงสุด (เทียบเท่าหนังสือราชการหรือรายงาน
ทางวิชาการที่ยื่นต่อหน่วยงาน) ไม่ใช่แค่ "ภาษาเขียนที่ดูเรียบร้อย" ทั่วไป** ก่อนปล่อยผ่านทุกประโยค ให้ลองอ่าน
เทียบว่าถ้าเปลี่ยนบริบทเป็นหนังสือราชการ/รายงานที่ต้องยื่นต่อผู้บริหารสถานศึกษา ประโยคนี้ใช้ได้เลยหรือไม่ ถ้า
ฟังดู "เหมือนพูดคุย" หรือ "เหมือนงานเขียนนักเรียนทั่วไป" แม้จะไม่มีคำผิดหลักไวยากรณ์ ก็ยังถือว่าไม่ผ่าน

**คำ/สำนวนที่ยกระดับความเป็นทางการ (ใช้แทนคำวิชาการทั่วไปที่ "เป็นทางการแต่ยังธรรมดา")**:

| ระดับวิชาการทั่วไป (ยังไม่พอ) | ระดับราชการ/ทางการขั้นสูง (เป้าหมาย) |
|---|---|
| ทำโครงงานนี้เพื่อ... | จัดทำโครงงานนี้ขึ้นโดยมีความประสงค์เพื่อ... |
| มีปัญหาเรื่อง... | ปรากฏปัญหาเกี่ยวกับ... / ประสบปัญหาในด้าน... |
| ทำให้เกิดผลเสีย | ก่อให้เกิดผลกระทบในทางลบ |
| ต้องแก้ไข | จำเป็นต้องได้รับการแก้ไข / มีความจำเป็นที่จะต้องดำเนินการแก้ไข |
| ดังนั้นจึงทำ... | ด้วยเหตุนี้ คณะผู้จัดทำจึงเห็นควรดำเนินการ... |
| ใช้ได้ดี | สามารถนำไปใช้งานได้อย่างมีประสิทธิภาพ |
| เพื่อให้ดีขึ้น | เพื่อให้การดำเนินงานเป็นไปอย่างมีประสิทธิภาพยิ่งขึ้น |
| นอกจากนี้ | ทั้งนี้ / อนึ่ง / ประกอบกับ (เลือกใช้ตามบริบท ไม่ซ้ำคำเดียวทั้งเล่ม) |

**คำเปิด/ปิดประเด็นที่ให้น้ำหนักทางการสูง** ใช้สลับกับคลังคำในข้อ 4 เพื่อยกระดับ ไม่ใช่แทนที่ทั้งหมด:

- เปิดประเด็นเชิงเหตุผล: "ด้วยเหตุที่..." / "เนื่องด้วย..." / "โดยที่..."
- เชื่อมเหตุ-ผลระดับสูง: "จึงเป็นเหตุให้..." / "ส่งผลให้..." / "เป็นผลให้..."
- ปิดประเด็น/สรุป: "ด้วยเหตุผลดังกล่าวข้างต้น คณะผู้จัดทำจึง..." / "จากสภาพปัญหาดังกล่าว จึงมีความจำเป็นที่จะต้อง..."

**กฎเรื่องคำศัพท์ต้องเชื่อมกับปัญหาที่กล่าวไว้ (สำคัญ — ป้องกันภาษาลอย ไม่เจาะจงโครงงาน)**: คำศัพท์หลักที่ใช้
บรรยายปัญหา/สาเหตุ/ผลกระทบในที่มาและความสำคัญ ต้องถูกหยิบมาใช้ซ้ำอย่างสอดคล้องกันในทุกหัวข้อถัดไปที่
เกี่ยวข้อง (วัตถุประสงค์ ขอบเขต ประโยชน์) **ห้ามเปลี่ยนไปใช้คำทั่วไปที่ไม่เจาะจงกับปัญหาที่ระบุไว้จริง** เช่น ถ้า
ที่มาฯ ระบุปัญหาว่า "ผักสวนครัวเหี่ยวเฉาเนื่องจากขาดการรดน้ำสม่ำเสมอในวันหยุด" วัตถุประสงค์/ขอบเขต/
ประโยชน์ ต้องใช้คำว่า "ความชื้นในดิน" "การรดน้ำสม่ำเสมอ" "ผักสวนครัว" ที่เจาะจงตรงกัน ไม่ใช่เปลี่ยนไปใช้คำ
กว้าง ๆ เช่น "การดูแลพืช" หรือ "การเกษตร" ที่ไม่ได้ผูกกับปัญหาที่กล่าวไว้จริง

**ตัวอย่างเทียบก่อน-หลัง (ยกระดับจากวิชาการทั่วไป เป็นระดับราชการ)**:

| ระดับวิชาการทั่วไป | ระดับราชการ/ทางการขั้นสูง |
|---|---|
| โครงงานนี้ทำขึ้นเพื่อแก้ปัญหาผักเหี่ยวเฉาในแปลงผักของโรงเรียน | คณะผู้จัดทำได้จัดทำโครงงานนี้ขึ้นโดยมีความประสงค์เพื่อแก้ไขปัญหาผักสวนครัวเหี่ยวเฉาในแปลงผักของโรงเรียน ซึ่งปรากฏขึ้นอย่างต่อเนื่อง |
| ปัญหานี้เกิดจากการรดน้ำที่ไม่สม่ำเสมอ ทำให้ผักได้รับความเสียหาย | ปัญหาดังกล่าวมีสาเหตุมาจากการรดน้ำที่ไม่สม่ำเสมอ ส่งผลให้ผักสวนครัวได้รับความเสียหายเป็นลำดับถัดมา |

## รูปแบบการอ้างอิงงานวิจัย (Citation format — กฎสำคัญที่พลาดบ่อย)

**ค่าเริ่มต้นของสกิลนี้ (ใช้เสมอ เว้นแต่ผู้ใช้/สถาบันระบุรูปแบบอื่นชัดเจน): ใช้การอ้างอิงแบบท้ายประโยค
(trailing/parenthetical citation) เท่านั้น** คือวางชื่อผู้แต่งและปีไว้ในวงเล็บท้ายประโยคหรือท้ายข้อความที่นำมา
กล่าวถึง ไม่ใช่การอ้างอิงแบบต้นประโยค (narrative citation) ที่ขึ้นต้นด้วยชื่อผู้แต่งตามด้วย "กล่าวว่า" ซึ่งเป็น
รูปแบบ APA สากลที่พบได้ แต่ **ไม่ใช่ธรรมเนียมที่นิยมในการเขียนที่มาฯ ของโครงงาน/งานวิจัยไทยส่วนใหญ่**
และเป็นจุดที่พลาดบ่อยเมื่อเขียนตามความเคยชินแบบภาษาอังกฤษ

**รูปแบบ**: `...ข้อความ/ประเด็นที่นำมากล่าวถึง... (ชื่อผู้แต่ง, ปีพิมพ์)`

- ✅ ถูก (ท้ายประโยค): "การเรียนรู้แบบร่วมมือช่วยส่งเสริมทักษะการคิดวิเคราะห์ของผู้เรียนได้อย่างมีนัยสำคัญ
  (สมชาย ใจดี, 2565)"
- ❌ ผิด (ต้นประโยคแบบ APA ฝรั่ง): "สมชาย ใจดี (2565) กล่าวว่าการเรียนรู้แบบร่วมมือช่วยส่งเสริมทักษะการคิด
  วิเคราะห์ของผู้เรียนได้อย่างมีนัยสำคัญ"
- ❌ ผิด (ต้นประโยค): "ตามที่สมชาย ใจดี (2565) ได้กล่าวไว้ว่า..."

**การอ้างอิงหลายแหล่งในประโยคเดียว**: คั่นด้วยเครื่องหมายอัฒภาค (;) ในวงเล็บเดียวกัน เช่น "...ประเด็นดังกล่าว
(สมชาย ใจดี, 2565; วรรณา สุขใจ, 2564)"

**ข้อยกเว้นเดียวที่อนุญาตให้เอ่ยชื่อผู้แต่งในเนื้อความได้**: ย่อหน้าที่ต้อง "เปรียบเทียบงานวิจัย/สิ่งประดิษฐ์ที่
เกี่ยวข้องทีละชิ้น" ในชั้น 3 (ดูแม่แบบใน `reference/01-thima-khwamsamkhan.md`) ซึ่งจำเป็นต้องแยกให้ชัดว่า
งานชิ้นไหนศึกษาอะไร แม้ในกรณีนี้ก็ให้ขึ้นต้นด้วยคำนามอื่นแทนชื่อบุคคล เช่น "งานวิจัยของสมชาย ใจดี (2565)
ได้ศึกษา..." ไม่ใช่ขึ้นต้นด้วยชื่อบุคคลตรง ๆ ทันที

ถ้าผู้ใช้ระบุมาว่าสถาบัน/ครูที่ปรึกษากำหนดรูปแบบอื่น (เช่น เชิงอรรถ, Vancouver, หรือ narrative citation) ให้ทำ
ตามที่ผู้ใช้ระบุแทนกฎเริ่มต้นนี้

## 8. ตัวอย่างการแก้ประโยคจากภาษาพูดเป็นภาษาทางการ (ก่อน → หลัง)

| ก่อนแก้ (ภาษาพูด/ไม่เป็นทางการ) | หลังแก้ (ภาษาทางการ) |
|---|---|
| พวกเราเลยอยากทำเครื่องนี้ขึ้นมาเพราะมันเจ๋งดี | คณะผู้จัดทำจึงมีแนวคิดที่จะพัฒนาเครื่องดังกล่าวขึ้น เนื่องจากเล็งเห็นถึงประโยชน์ที่จะเกิดขึ้นกับกลุ่มเป้าหมาย |
| ปัญหานี้มันเกิดขึ้นบ่อยมากในโรงเรียน | ปัญหาดังกล่าวเกิดขึ้นเป็นประจำภายในโรงเรียน |
| เราจะเอาเซนเซอร์มาติดแล้วให้มันวัดความชื้น | เครื่องดังกล่าวติดตั้งเซนเซอร์เพื่อวัดค่าความชื้นในดินโดยอัตโนมัติ |
| ซึ่งจะทำให้ทุกคนพอใจมากขึ้น | การดำเนินงานดังกล่าวจึงคาดว่าจะช่วยเพิ่มความพึงพอใจของกลุ่มเป้าหมายได้ |

- [ ] ทุกประโยคมีประธานชัดเจน อ่านจบในตัวเองได้โดยไม่ต้องพึ่งประโยคก่อนหน้า

- [ ] ไม่มีคำภาษาพูดตามตารางข้อ 5 หลงเหลืออยู่
- [ ] คำศัพท์หลักของโครงงาน (ชื่อสิ่งประดิษฐ์/ตัวแปรหลัก) ใช้คำเดียวกันตลอดทั้งเล่ม ไม่สลับคำพ้องความหมาย
- [ ] การเว้นวรรคถูกต้องตามข้อ 6
- [ ] ไม่มีสรรพนามบุรุษที่ 1/2 (หนู/ผม/ดิฉัน/คุณ) หลงเหลืออยู่ ใช้ "คณะผู้จัดทำ" แทน
- [ ] การอ้างอิงทุกจุดเป็นแบบท้ายประโยค (ผู้แต่ง, ปี) ไม่มีจุดไหนขึ้นต้นประโยคด้วยชื่อผู้แต่งตามด้วย "กล่าวว่า"
      แบบ narrative citation (เว้นแต่ผู้ใช้ระบุให้ใช้รูปแบบอื่น)

      บริบทหนังสือราชการแล้วต้องผ่าน
- [ ] คำศัพท์ที่บรรยายปัญหา/สาเหตุในที่มาฯ ถูกใช้ซ้ำอย่างเจาะจงตรงกันในหัวข้อถัดไปที่เกี่ยวข้อง ไม่เปลี่ยนไปใช้
      คำทั่วไปที่ไม่ผูกกับปัญหาที่ระบุไว้จริง
