# ตัวช่วยเขียนบทที่ 2 โครงงาน/งานวิจัยไทย

## หลักสำคัญ

บทที่ 2 ตอบว่า **“มีองค์ความรู้ ทฤษฎี และผลงานก่อนหน้าใดรองรับโครงงานนี้ และสิ่งเหล่านั้นเชื่อมกับโครงงานอย่างไร”**
ไม่ใช่เหตุผลว่าทำไมต้องทำ (บทที่ 1) และไม่ใช่ขั้นตอนว่าจะทำอย่างไร (บทที่ 3)

ห้ามสร้างชื่อผู้แต่ง ปี ชื่อผลงาน ผลการศึกษา ตัวเลข DOI URL โรงเรียน หรือหน่วยงานขึ้นเอง ใช้เฉพาะข้อมูลจาก
ไฟล์จริงที่ตรวจแล้วหรือแหล่งที่เปิดตรวจสอบได้จริง หากยืนยันไม่ได้ให้ใช้ placeholder วงเล็บเหลี่ยมและแจ้งผู้ใช้
เป็นรายการตอนส่งมอบ

## ก่อนเขียน

1. ถามหรืออนุมานจากเอกสารให้ชัดว่าโครงงานเป็นประเภทใด: สิ่งประดิษฐ์ ทดลองวิทยาศาสตร์ พัฒนาโปรแกรม
   สำรวจ สังคมศาสตร์ หรือวิจัยในชั้นเรียน หากยังไม่ทราบ **ต้องถามผู้ใช้ก่อนเขียนเนื้อหาจริง**
2. เก็บชื่อเรื่อง ปัญหา วัตถุประสงค์ ตัวแปร/องค์ประกอบหลัก ผลงานที่จะสร้าง กลุ่มเป้าหมาย และข้อกำหนดของสถาบัน
   โดยเฉพาะรูปแบบอ้างอิงและหัวข้อบังคับ
3. หากมีร่างบทที่ 1 หรือบทที่ 3 ให้อ่านเพื่อกำหนดขอบเขตและคำศัพท์ให้สอดคล้องกัน แต่ห้ามนำข้อความมาซ้ำ
4. หากมี Excel/CSV หรือไฟล์ข้อมูลอื่น ต้องเปิดอ่านและตรวจค่าจากไฟล์จริงก่อนใช้ อย่าเชื่อตัวเลขที่บอกปากเปล่า
5. อ่าน [โครงสร้างตามประเภทโครงงาน](reference/01-structure-by-project-type.md) ก่อนวางหัวข้อ

## ขั้นตอนบังคับ

### 1. วางแผนคำค้นและค้นเว็บก่อนเขียน

WebSearch เป็นขั้นตอนบังคับเสมอ ค้นทั้งภาษาไทยและภาษาอังกฤษตามแนวคิด ตัวแปร เทคโนโลยี วิธีแก้ปัญหา
และกลุ่มเป้าหมาย เปิดอ่านแหล่งต้นฉบับ ไม่อาศัยข้อความย่อจากหน้าผลค้นหาเพียงอย่างเดียว ทำตาม
[การค้นและตรวจสอบแหล่ง](reference/02-search-and-source-validation.md)

หากค้นไม่พบงานที่เกี่ยวข้องจริงหรือเข้าถึงข้อมูลสำคัญไม่ได้ ให้บอกข้อจำกัดตรง ๆ และใส่ placeholder ห้ามเติม
แหล่งอ้างอิงที่คาดว่าน่าจะมีอยู่

### 2. ยืนยันระบบอ้างอิง

ใช้คู่มือของสถาบันผู้ใช้เป็นหลัก ถ้าไม่มีข้อกำหนด ให้ใช้ระบบนาม-ปีตาม APA และใช้ **narrative citation เป็น
ค่าเริ่มต้นในการสรุปงานทีละชิ้น** เช่น “ชื่อผู้แต่ง (ปี) ศึกษา... ผลการศึกษาพบว่า...” ส่วน parenthetical citation
ใช้ได้เมื่อเน้นสาระหรือสังเคราะห์หลายแหล่ง ต้องใช้รูปแบบให้สม่ำเสมอและจับคู่กับรายการอ้างอิงทุกครั้ง อ่าน
[คู่มือรูปแบบอ้างอิง](reference/03-citation-style.md) ก่อนเขียนส่วนงานวิจัยที่เกี่ยวข้อง

### 3. จัดหมวดหมู่และเขียนจากองค์ความรู้ไปสู่การสังเคราะห์

ใช้หัวข้อเท่าที่เกี่ยวข้องจริง:

- แนวคิดและคำสำคัญที่ต้องเข้าใจ
- ทฤษฎี/หลักการที่ใช้กำหนดตัวแปร ออกแบบผลงาน หรืออธิบายผล
- งานวิจัย/สิ่งประดิษฐ์ที่เกี่ยวข้องในประเทศและต่างประเทศ
- กรอบแนวคิดการวิจัยหรือผังความเชื่อมโยง (เมื่อเหมาะกับประเภทงาน)
- บทสรุปการสังเคราะห์และนัยต่อโครงงานนี้

หากมีหลายรายการ ให้จัดกลุ่มตามประเด็น ตัวแปร เทคโนโลยี วิธีแก้ หรือกลุ่มเป้าหมายก่อน ห้ามทำรายการยาว
1–20 โดยไม่มีหมวด งานในประเทศ/ต่างประเทศอาจเป็นหัวข้อย่อยภายในหมวด หรือเป็นหมวดหลักตามแบบสถาบัน
อ่าน [การสังเคราะห์และกรอบแนวคิด](reference/04-synthesis-and-framework.md) ระหว่างเขียน

### 4. ตรวจทันทีหลังแต่ละหัวข้อและตรวจทั้งบท

หลังเขียนแต่ละหัวข้อ ให้ตรวจแหล่งอ้างอิง ความเป็นทางการ ความซ้ำ และขอบเขตหน้าที่ของหัวข้อนั้นทันที
เมื่อครบทั้งบท ให้ทำการตรวจหลายรอบตาม [ตารางเจ้าของเนื้อหาและด่านคุณภาพ](reference/05-content-ownership-and-quality.md)
