# โครงสร้างบทที่ 2 ตามประเภทโครงงาน

## ตารางเจ้าของเนื้อหาหลัก

| ส่วน | คำถามที่ตอบ | ไม่ควรเขียน |
|---|---|---|
| แนวคิด/คำสำคัญ | ผู้อ่านต้องเข้าใจคำหรือมิติใดก่อน | ประวัติทั่วไปที่ไม่ถูกใช้ต่อ |
| ทฤษฎี/หลักการ | หลักใดอธิบายตัวแปรหรือกำกับการออกแบบ | ขั้นตอนทดลองหรือสเปกละเอียด |
| งานที่เกี่ยวข้อง | ใครศึกษา/พัฒนาอะไร ด้วยวิธีใด พบอะไร และเกี่ยวข้องอย่างไร | การคัดลอกบทคัดย่อหรือสรุปผลลอย ๆ |
| กรอบแนวคิด | ปัจจัย/องค์ประกอบเชื่อมโยงกันอย่างไร | แผนดำเนินงานตามเวลา |
| สรุปบท | องค์ความรู้ทั้งหมดนำไปสู่แนวทางของโครงงานนี้อย่างไร | เหตุผลความสำคัญซ้ำบทที่ 1 |

## การให้น้ำหนักตามประเภท

- **สิ่งประดิษฐ์/นวัตกรรม**: เน้นหลักการทำงาน เทคโนโลยี/วัสดุ เกณฑ์ออกแบบ และเปรียบเทียบสิ่งประดิษฐ์เดิม
- **ทดลองวิทยาศาสตร์**: เน้นกลไกทางวิทยาศาสตร์ ทฤษฎีที่อธิบายตัวแปร และผลการทดลองก่อนหน้าที่เทียบกันได้
- **พัฒนาโปรแกรม**: เน้นแนวคิดโดเมน สถาปัตยกรรม/อัลกอริทึมที่เกี่ยวข้อง หลักการใช้งาน และระบบเดิม
- **สำรวจ**: เน้นนิยามเชิงแนวคิด มิติของตัวแปร เครื่องมือวัดที่ผ่านการใช้ และงานในประชากรใกล้เคียง
- **สังคมศาสตร์**: เน้นทฤษฎี ความสัมพันธ์ของตัวแปร บริบท และการสังเคราะห์ข้อค้นพบที่สอดคล้องหรือขัดแย้ง
- **วิจัยในชั้นเรียน**: เน้นทฤษฎีการเรียนรู้ เนื้อหาวิชา นวัตกรรมการสอน การวัดผล และงานกับผู้เรียนระดับใกล้เคียง

ไม่บังคับทุกงานให้มีกรอบแนวคิด หากเป็นสิ่งประดิษฐ์หรือโปรแกรมที่ไม่มีตัวแปรเชิงเหตุผล อาจใช้ผัง “หลักการ →
ข้อกำหนดการออกแบบ → คุณลักษณะผลงาน → เกณฑ์ประเมิน” แทน หรือไม่ใส่ถ้าสถาบันไม่กำหนด
