# ตารางเจ้าของเนื้อหาและด่านคุณภาพ

## Content Ownership Table

| เนื้อหา | เจ้าของ | หากพบซ้ำ |
|---|---|---|
| ความหมาย/องค์ประกอบของแนวคิด | แนวคิดที่เกี่ยวข้อง | ตัดจากสรุปงาน เหลือเฉพาะวิธีใช้แนวคิดในงานนั้น |
| กลไก เหตุผลเชิงทฤษฎี หรือหลักวิทยาศาสตร์ | ทฤษฎี/หลักการ | ตัดคำอธิบายซ้ำจากงานวิจัย เหลือข้อค้นพบ |
| วัตถุประสงค์ วิธี กลุ่ม และผลของงานก่อนหน้า | งานวิจัยที่เกี่ยวข้อง | ไม่ย้ายไปหัวข้อทฤษฎี |
| การเปรียบเทียบ ข้อค้นพบร่วม ความต่าง ช่องว่าง | ย่อหน้าสังเคราะห์ของแต่ละหมวด | ไม่สรุปซ้ำทีละงานในบทสรุป |
| ความสัมพันธ์ขององค์ประกอบในงานปัจจุบัน | กรอบแนวคิด | ไม่ปนเป็นขั้นตอนดำเนินงาน |
| สิ่งที่องค์ความรู้ทั้งหมดสนับสนุนในโครงงานนี้ | สรุปท้ายบท | กล่าวครั้งเดียว ไม่ทวนทุกแหล่ง |
| เหตุผลว่าปัญหาสำคัญเพียงใด | บทที่ 1 | ตัดออกจากบทที่ 2 |
| ขั้นตอน อุปกรณ์จำนวนละเอียด การเก็บ/วิเคราะห์ข้อมูล | บทที่ 3 | ตัดออกจากบทที่ 2 |

## ตรวจ 5 รอบก่อนส่ง

1. **ขอบเขต**: ทุกย่อหน้าตอบหน้าที่ของหัวข้อและไม่ล้ำไปบทที่ 1/3
2. **ความซ้ำ**: แนวคิดเดียวกันอธิบายเต็มเพียงครั้งเดียว; จุดอื่นอ้างเชื่อมสั้น ๆ
3. **หลักฐาน**: ตรวจชื่อ ปี ชื่อเรื่อง วิธี ผล URL/DOI จากต้นฉบับ และตรวจตัวเลขกับไฟล์จริง
4. **การสังเคราะห์**: งานถูกจัดหมวด มีการเปรียบเทียบ และบทสรุปบอกนัยต่อโครงงาน ไม่ใช่รายชื่อเรียงต่อกัน
5. **ภาษาและอ้างอิง**: ประโยคสมบูรณ์ เป็นทางการ คำศัพท์หลักสม่ำเสมอ citation ตรงรายการอ้างอิง และรูปแบบ
   ตรงคู่มือสถาบัน

## ภาษาไทยเชิงวิชาการ

- ไม่ขึ้นต้นประโยค/ย่อหน้าด้วย “ซึ่ง” “และ” หรือ “แต่”; ใช้ประธานให้ชัด
- ใช้คำเชื่อมตามหน้าที่ เช่น “นอกจากนี้” “อย่างไรก็ตาม” “ในทางตรงกันข้าม” “กล่าวโดยสรุป”
- หลีกเลี่ยงภาษาพูด เช่น เยอะ โอเค ดีมาก ๆ เอามาใช้; ใช้ จำนวนมาก เหมาะสม มีประสิทธิผล นำมาประยุกต์ใช้
- รักษาคำศัพท์หลักให้เหมือนกันทั้งบท ไม่สลับคำพ้องจนคลุมเครือ
- อย่าใช้ “มีนัยสำคัญ” เว้นแต่ต้นฉบับรายงานผลสถิติรองรับ
- คงความเป็นกลาง แยก “ผลที่แหล่งรายงาน” ออกจาก “การตีความเชื่อมโยงของผู้เขียน” ให้ชัด

### ระดับความเป็นทางการ: เทียบเท่าหนังสือราชการ (มาตรฐานเดียวกับบทที่ 1)

“เป็นทางการ” ในที่นี้หมายถึงระดับภาษาราชการ/รายงานวิชาการที่ยื่นต่อหน่วยงาน ไม่ใช่แค่ภาษาเขียนที่ดูเรียบร้อย
ทั่วไป ก่อนปล่อยผ่านแต่ละย่อหน้า ให้ลองอ่านเทียบบริบทหนังสือราชการ/รายงานที่ยื่นต่อผู้บริหารสถานศึกษา ถ้า
ฟังดู “เหมือนพูดคุย” หรือ “เหมือนงานเขียนนักเรียนทั่วไป” แม้ไวยากรณ์ถูก ก็ยังถือว่าไม่ผ่าน ตัวอย่างการยกระดับ
คำ: “ศึกษาเรื่องนี้เพื่อ” → “ดำเนินการศึกษาโดยมีความประสงค์เพื่อ”, “พบว่ามีปัญหา” → “ปรากฏปัญหาเกี่ยวกับ”,
“ทำให้ดีขึ้น” → “ส่งผลให้มีประสิทธิภาพยิ่งขึ้น” คำศัพท์หลักที่ใช้บรรยายแนวคิด/ทฤษฎี/งานวิจัยต้องตรงกับคำที่
บทที่ 1 ใช้บรรยายปัญหาไว้ ห้ามเปลี่ยนไปใช้คำทั่วไปที่ไม่เจาะจงกับโครงงานนี้
