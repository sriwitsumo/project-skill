# ตัวแปรที่เกี่ยวข้อง — คู่มือเจาะลึก

## หน้าที่ของหัวข้อนี้ (และทำไมถึงแยกออกมาจากสมมติฐาน)

ตอบคำถาม: **"โครงงานนี้มีตัวแปรอะไรบ้าง แบ่งเป็นตัวแปรต้น ตัวแปรตาม ตัวแปรควบคุม"** เขียนเป็น **รายการสั้น ๆ**
เท่านั้น ไม่ใช่ประโยคบรรยาย เพราะประโยคบรรยายว่าตัวแปรสัมพันธ์กันอย่างไรเป็นหน้าที่ของหัวข้อสมมติฐานไปแล้ว
(ดู `reference/03-sommutithan.md`) หัวข้อนี้ทำหน้าที่แค่ "ประกาศรายชื่อ" ให้ผู้อ่านเห็นภาพรวมตัวแปรทั้งหมด
ก่อนไปอ่านรายละเอียดวิธีดำเนินงานในบทที่ 3

**ต้องมีหัวข้อนี้เมื่อไหร่**: ใช้เกณฑ์เดียวกับหัวข้อสมมติฐาน — ถ้าโครงงานมีตัวแปรต้น-ตัวแปรตามที่จะทดสอบ
ความสัมพันธ์กันจริง (ทดลองวิทยาศาสตร์, สิ่งประดิษฐ์ที่ทดสอบประสิทธิภาพเทียบเกณฑ์) ให้มีหัวข้อนี้ ถ้าเป็นโครงงาน
พัฒนาโปรแกรม/สำรวจ/สังคมศาสตร์เชิงบรรยายที่ไม่มีตัวแปรต้น-ตามชัดเจน ให้ข้ามหัวข้อนี้ไปได้เลย (เหมือนที่ข้าม
สมมติฐานได้)

## รูปแบบการเขียน (สั้นที่สุดเท่าที่จะสั้นได้)

```
ตัวแปรต้น    [ระบุสิ่งที่เปลี่ยน/ควบคุมโดยผู้ทำ]
ตัวแปรตาม    [ระบุสิ่งที่วัดผล]
ตัวแปรควบคุม  [ระบุสิ่งที่ต้องคงที่ ไล่ตามกฎเหล็กด้านล่าง]
```

**ตัวอย่าง** (ต่อจากเครื่องรดน้ำต้นไม้อัตโนมัติ):

> ตัวแปรต้น: ค่าความชื้นในดินที่ใช้เป็นเกณฑ์สั่งเปิด-ปิดปั๊มน้ำ (40%, 50%, 60%)
> ตัวแปรตาม: อัตราการเจริญเติบโตของผักบุ้งจีน (ความสูงเฉลี่ยและจำนวนใบต่อต้นเมื่อครบ 30 วัน)
> ตัวแปรควบคุม: ชนิด/ปริมาณดินที่ใช้ปลูก, ปริมาณแสงแดดที่ได้รับต่อวัน, พันธุ์ผักบุ้งจีนที่ใช้ทดลอง

สังเกตว่าไม่มีประโยคอธิบายเหตุผล "ทำไมต้องควบคุมตัวแปรนี้" ปนอยู่เลย — เหตุผลแบบนั้นเขียนได้ที่เดียวคือใน
`reference/03-sommutithan.md` เท่านั้น (ดูหัวข้อ "กฎเหล็ก: ตัวแปรต้น ตัวแปรตาม และตัวแปรควบคุม ต้องสัมพันธ์
กันจริง") ถ้าพบว่ากำลังจะพิมพ์เหตุผลยาวในหัวข้อนี้ ให้ตัดออกแล้วย้ายไปหัวข้อสมมติฐานแทน

## กฎเหล็ก (อ้างอิงจากหัวข้อสมมติฐาน — ต้องยึดที่นี่ด้วย)

ตัวแปรควบคุมทุกตัวต้องเป็นสิ่งที่ **มีผลกระทบจริงต่อตัวแปรตามได้ถ้าไม่ควบคุมไว้** เท่านั้น ห้ามใส่มาเพียงเพื่อให้
ครบ 3 ตัวแปรตามแบบฟอร์ม (ดูเทคนิคตรวจสอบแบบเต็มใน `reference/03-sommutithan.md`)

## ความยาว

หัวข้อนี้ควรยาวไม่เกิน 2-4 บรรทัด (แค่รายชื่อตัวแปร 3 ประเภท) เพราะบทที่ 1 ทั้งบทมีเป้าหมายความยาวรวม
ประมาณ 1.5 หน้าเท่านั้น (ดู SKILL.md หัวข้อ "เกณฑ์ความยาวเริ่มต้น") ถ้าเขียนยาวเกินนี้ แปลว่ากำลังปนเนื้อหา
ของหัวข้อสมมติฐานหรือขอบเขตเข้ามา ให้ย้อนกลับไปแยกหน้าที่ให้ชัดตามตารางความเป็นเจ้าของเนื้อหาใน
`reference/08-pongkan-wangwon.md`

## Checklist ก่อนถือว่าหัวข้อนี้เสร็จ

- [ ] เป็นรายการสั้น ๆ 3 บรรทัด (ต้น/ตาม/ควบคุม) ไม่ใช่ประโยคบรรยาย
- [ ] ไม่มีประโยคอธิบายเหตุผล/ความสัมพันธ์ปนอยู่ (ย้ายไปสมมติฐาน)
- [ ] ตัวแปรควบคุมทุกตัวผ่านกฎเหล็ก ไม่ใช่ใส่มาลอย ๆ
- [ ] ถ้าโครงงานไม่มีตัวแปรต้น-ตามชัดเจน ให้ข้ามหัวข้อนี้ไปเลย ไม่ต้องฝืนใส่
